# Estado de conservación de las cuencas del Caribe venezolano

Evaluación del estado de conservación 2000–2025 en las cuencas de los ríos **Tocuyo, Aroa, Yaracuy y Urama** (Venezuela), mediante análisis multicriterio **AHP–DPSI** en ArcGIS Pro.

Tesis de la Maestría en Ingeniería Ambiental, UNELLEZ (San Carlos).

## Visor interactivo

**https://dalpgis.github.io/tesis-estados-conservacion/**

Muestra el Índice de Estado de Conservación Ecosistémica (IEEC) 2000–2025, los subíndices DPSI, el cambio ΔIEEC y las trayectorias, los puntos calientes de pérdida (Getis-Ord Gi*), los focos de calor 2025 y la prioridad de intervención por cuenca.

Se necesita conexión a Internet (ArcGIS Maps SDK for JavaScript y Chart.js se cargan desde sus servidores).
